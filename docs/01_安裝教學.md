# 01 安裝教學：從零開始

這份文件帶你從一台什麼都沒裝的 Windows 電腦，裝到可以執行所有範例。
全部做完大約需要 30～60 分鐘，大部分時間在等下載。

---

## 安裝前先確認電腦規格

| 項目 | 最低需求 | 建議 | 怎麼查 |
| --- | --- | --- | --- |
| 作業系統 | Windows 10 / 11 | — | — |
| 記憶體（RAM） | 8 GB | 16 GB 以上 | 工作管理員 → 效能 → 記憶體 |
| 硬碟空間 | 15 GB | 25 GB 以上 | 檔案總管 → 本機 |
| 顯示卡 | 不一定要有 | NVIDIA 顯卡會快很多 | 工作管理員 → 效能 → GPU |
| 網路 | 要能下載約 10 GB | — | — |

> **沒有 NVIDIA 顯卡也可以跑**，模型會改用 CPU，只是比較慢（一題可能等十幾秒到一分鐘）。
> AMD 顯卡在 Windows 上大多也會改用 CPU。

---

## 方法一：一鍵安裝（推薦給學員）

1. 把整個 `LangChain_Daigo` 資料夾複製到電腦上（建議放在 D 槽或桌面）。
2. 在資料夾空白處按住 `Shift` + 滑鼠右鍵 → 選「在這裡開啟 PowerShell 視窗」（或「在終端機中開啟」）。
3. 輸入：

   ```powershell
   .\setup.ps1
   ```

4. 如果出現紅字「**因為這個系統上已停用指令碼執行**」，先輸入下面這行，再重新執行 `.\setup.ps1`：

   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   ```

   這行的意思是「允許執行自己電腦上的腳本」，只影響目前這個使用者。

腳本會自動完成下面方法二的所有步驟。

---

## 方法二：手動一步一步安裝（推薦給講師，了解每一步在做什麼）

### 步驟 1：安裝 Python 3.11

1. 到 [python.org/downloads](https://www.python.org/downloads/) 下載 Python 3.11 版。
2. 安裝時**一定要勾選最下面的「Add python.exe to PATH」**。
3. 安裝完打開 PowerShell 確認：

   ```powershell
   py -3.11 --version
   ```

   看到 `Python 3.11.x` 就成功了。

> 為什麼用 3.11？這是目前各套件支援最穩定的版本。3.12 通常也可以，太新的版本有時套件還沒跟上。

### 步驟 2：安裝 Ollama

Ollama 是一個讓你在自己電腦上執行 AI 模型的程式。

**方式 A：用 winget（Windows 內建的套件管理工具）**

```powershell
winget install --id Ollama.Ollama -e
```

**方式 B：到官網下載**

到 [ollama.com/download](https://ollama.com/download) 下載 Windows 版安裝檔，雙擊安裝。

**確認安裝成功：** 重新開一個 PowerShell 視窗，輸入：

```powershell
ollama --version
```

看到版本號就成功了。安裝完 Ollama 會自動在背景執行，右下角工作列會有一隻羊駝圖示。

> 如果顯示「找不到 ollama」：把 PowerShell 關掉重開。還是不行就重新開機。

### 步驟 3：下載 Gemma 4 模型

```powershell
ollama pull gemma4:e4b
```

檔案大約 7～10 GB，會顯示下載進度條。

**Gemma 4 有好幾種大小，怎麼選？**

| 版本 | 大小 | 適合的電腦 | 特色 |
| --- | --- | --- | --- |
| `gemma4:e2b` | 最小 | 8 GB 記憶體 | 最快，但比較容易用錯工具 |
| `gemma4:e4b` | 中 | 16 GB 記憶體 | **本專案預設**，速度和能力平衡 |
| `gemma4:12b` | 較大 | 16 GB 以上，最好有顯卡 | 比較聰明，比較慢 |
| `gemma4:26b`、`31b` | 很大 | 32 GB 以上 + 好顯卡 | 一般筆電跑不動 |

**下載完先試玩一下：**

```powershell
ollama run gemma4:e4b
```

會出現 `>>>` 提示，直接打中文跟它聊天。輸入 `/bye` 離開。

> **AMD 顯卡的電腦可能會在這一步出錯**，錯誤訊息類似：
> `llama-server process has terminated ... Gemma4Assistant requires ctx_other to be set`
> 原因是 Ollama 想用 AMD 顯卡跑模型，但顯卡記憶體配置失敗。
> **不用擔心，可以直接跳過這一步。** 我們的 Python 範例程式已經設定成只用 CPU（`config.py` 的 `USE_GPU = False`），不會遇到這個問題。到步驟 6 用 `step1_hello.py` 確認就好。

### 步驟 4：建立 Python 虛擬環境

虛擬環境就像一個獨立的房間，這個專案裝的套件只放在這個房間裡，不會影響電腦上其他 Python 專案。

```powershell
# 切換到專案資料夾（路徑換成你自己的）
cd D:\LangChain_Daigo

# 建立虛擬環境，會多出一個 .venv 資料夾
py -3.11 -m venv .venv

# 啟動虛擬環境
.\.venv\Scripts\Activate.ps1
```

啟動成功後，命令列最前面會出現 `(.venv)`。

> **每次開新的 PowerShell 視窗，都要重新啟動虛擬環境**（執行 `Activate.ps1` 那行）。
> 忘記啟動是最常見的錯誤，會出現「No module named langchain」。

### 步驟 5：安裝 Python 套件

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

會安裝這些套件：

| 套件 | 用途 |
| --- | --- |
| `langchain` | LangChain 主套件，包含 `create_agent` |
| `langchain-ollama` | 讓 LangChain 能連到 Ollama 的模型 |
| `langchain-huggingface` | 讓 LangChain 能使用本機的 Embeddings 模型 |
| `sentence-transformers` | Embeddings 模型的核心（會一起裝 PyTorch，檔案比較大） |
| `langchain-text-splitters` | 把文件切段的工具 |

`sentence-transformers` 會一起裝 PyTorch，大約要下載 1～2 GB，請耐心等待。

### 步驟 6：確認一切正常

```powershell
python src\step1_hello.py
```

看到 AI 用中文自我介紹，就代表全部裝好了！

### 步驟 7：同步網站上的最新商品（選做）

`data/` 裡已經附上同步好的商品和規則。想更新成網站上最新的資料，執行：

```powershell
python scripts\sync_from_website.py
```

大約 1 分鐘，會更新 `data/products.json`（商品）和 `data/faq.md`（退換貨說明、服務條款）。

> 第一次執行會比較慢，因為 Ollama 要把模型載入記憶體。第二次就快多了。

## 常見問題排解

| 錯誤訊息或狀況 | 原因 | 解決方法 |
| --- | --- | --- |
| `No module named 'langchain'` | 沒有啟動虛擬環境 | 執行 `.\.venv\Scripts\Activate.ps1` |
| `因為這個系統上已停用指令碼執行` | PowerShell 安全設定 | 執行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| `Connection refused` 或 `連線被拒` | Ollama 沒有在執行 | 從開始選單打開 Ollama，或執行 `ollama serve` |
| `model "gemma4:e4b" not found` | 模型還沒下載 | 執行 `ollama pull gemma4:e4b` |
| 中文變成亂碼 | 終端機編碼問題 | 範例程式已經處理；自己寫的程式加上 `sys.stdout.reconfigure(encoding="utf-8")` |
| 回答非常慢（超過 1 分鐘） | 用 CPU 執行、或記憶體不夠 | 換成 `gemma4:e2b`；關掉其他吃記憶體的程式 |
| 第一次跑步驟 4 卡很久 | 正在下載 Embeddings 模型（約 1 GB） | 等它下載完，之後就不用再下載 |
| `ollama` 指令找不到 | 安裝後還沒重開終端機 | 關掉 PowerShell 重開，或重新開機 |
| `llama-server process has terminated`、`ErrorOutOfHostMemory`、`ctx_other` | Ollama 用 AMD 顯卡跑模型失敗 | 確認 `config.py` 的 `USE_GPU = False`（預設就是） |
| 下載模型時出現 `unexpected EOF` | 網路中斷 | 重新執行 `ollama pull gemma4:e4b`，會從中斷的地方繼續下載 |

---

## 解除安裝

想把東西都清掉的話：

1. 刪除模型：`ollama rm gemma4:e4b`
2. 解除安裝 Ollama：設定 → 應用程式 → 找到 Ollama → 解除安裝
3. 刪除專案資料夾裡的 `.venv` 資料夾
4. Embeddings 模型存在 `C:\Users\你的帳號\.cache\huggingface`，可以整個刪掉
